# Export-Import Bank of the United States (EXIM)

> EXIM is the official export credit agency of the United States federal government. It
> helps finance and facilitate US exports through export credit insurance, working capital
> guarantees, loan guarantees and direct loans. This file was GENERATED by API Evangelist
> from EXIM's own published surface on 2026-09-04; EXIM does not publish an llms.txt.

## Read this first

EXIM operates **no public API**. If you are an agent looking for a callable EXIM endpoint,
there is not one, and the honest answer is better than a plausible guess:

- The former Socrata/SODA open data portal at `data.exim.gov` was **decommissioned on
  2023-09-14** by EXIM's own announcement, and the host no longer resolves in DNS. Any
  OpenAPI, SDK, or tutorial describing `data.exim.gov`, SoQL queries, or an `X-App-Token`
  header against EXIM is describing a surface that no longer exists.
- What replaced it is **file distribution, not a service**: a Project Open Data v1.1
  (DCAT-US) catalog pointing at a quarterly CSV and a PDF data dictionary.
- `eximonline.exim.gov` is an authenticated human application portal for export-finance
  applicants. It publishes no developer documentation and no programmatic entry point.

## Machine-readable data

- [EXIM Open Data catalog (data.json)](https://img.exim.gov/s3fs-public/dataset/vbhv-d8am/data.json):
  Project Open Data v1.1 / DCAT-US catalog. One dataset. `conformsTo:
  https://project-open-data.cio.gov/v1.1/schema`. Anonymous GET, no key.
- [Authorizations From 10/01/2006 (CSV)](https://img.exim.gov/s3fs-public/dataset/vbhv-d8am/data-gov_fy26-q2.csv):
  every EXIM authorization approved since FY2007 — decision, date, country, program,
  policy type, NAICS, exporter, borrower. Updated quarterly. **The filename carries the
  fiscal quarter, so this URL changes every quarter — re-read data.json for the current
  file rather than pinning this address.**
- [Data dictionary (PDF)](https://img.exim.gov/s3fs-public/dataset/vbhv-d8am/EXIM_Data.gov_Report_Data_Dictionary.pdf):
  column definitions. PDF only; the schema is not machine-readable.
- [Data.gov organization page](https://catalog.data.gov/organization/exim): the canonical
  federal catalog entry. One dataset listed.

## EXIM Digital Archives (vendor-operated)

Historical EXIM records — annual reports, press releases, board materials, oral histories —
are served from an OCLC CONTENTdm tenant on an exim.gov address. The content is EXIM's; the
API is OCLC's product, so treat the contract as CONTENTdm's, not EXIM's.

- [Collections list (JSON)](https://www.digitalarchives.exim.gov/digital/api/collections) — 26 collections.
- [dmwebservices collection list](https://www.digitalarchives.exim.gov/digital/bl/dmwebservices/index.php?q=dmGetCollectionList/json) — CONTENTdm's legacy JSON API.
- IIIF Presentation API 2.0 manifests: `https://www.digitalarchives.exim.gov/iiif/{alias}:{id}/manifest.json`
  (example: `.../iiif/ExImPR01:4250/manifest.json`). Anonymous, no key.

## Products (not APIs)

Export Credit Insurance · Working Capital Guarantees · Loan Guarantees · Direct Loans ·
Country Limitation Schedule. These are financial instruments quoted per transaction and
applied for through [EXIM Online](https://eximonline.exim.gov/). None is exposed
programmatically.
